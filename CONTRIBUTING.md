# Contributing to retro-bot

Thanks for taking the time to contribute. retro-bot is a small project and
contributions are welcome — whether that's a bug fix, a new retro format,
or an improvement to the skill's instructions.

---

## Reporting issues

Use [GitHub Issues](https://github.com/cometogather/retro-bot/issues).

For bugs: describe what you expected to happen, what actually happened,
and which phase the issue occurred in. Attach the relevant portion of your
session if it helps.

For feature requests: describe the use case and why the current behavior
doesn't cover it.

---

## Submitting changes

1. Fork the repo and create a branch from `main`
2. Make your changes
3. Open a pull request with a clear description of what changed and why

For changes to `SKILL.md` specifically:

- Follow the copy-first versioning pattern: read the current version,
  apply your edits, write to a new version filename, move the old version
  to `archive/`
- Bump the version number (patch for small fixes, minor for new behavior,
  major for restructured workflow)
- Add a changelog entry at the bottom of `SKILL.md`
- Update the version history table in `README.md`

---

## What makes a good contribution

- Fixes a specific, reproducible issue
- Adds a retro format or action item type that covers a real gap
- Improves clarity without inflating the skill's token footprint
- Stays consistent with the existing tone (direct, practical, no jargon)
