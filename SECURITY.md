# Security Policy

## Scope

retro-bot is a plain-text skill for Claude. It contains no executable code,
no external API calls, and no data collection. The attack surface is minimal.

## Reporting a vulnerability

If you discover a security issue, please email CJammet@gather.co rather than
opening a public GitHub issue. Include a description of the issue and steps
to reproduce it.

We'll respond within 5 business days.
